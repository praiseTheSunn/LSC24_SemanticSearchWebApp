# SnapSeek - Interactive Multimedia Retrieval System

SnapSeek is a professional-grade platform for **video corpus moment retrieval**. It prioritizes **text-based queries** enhanced by comprehensive **metadata filters** including OCR text, activities/ADL, object tags, and color attributes. In addition to the primary search workflow, SnapSeek supports exploratory analysis through **neighbor browsing**, **similar-image retrieval**, **temporal navigation**, and **human-in-the-loop feedback**. The system is built on a robust foundation combining a **Milvus** vector database for embedding search with **Elasticsearch** for structured and full‑text indexing.
